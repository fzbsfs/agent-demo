# 算法补课计划（初级 Agent 岗够用版）

目标不是刷很多题，而是**把高频简单题的模式练熟**。
每天 30-45 分钟，做 1-2 题，坚持 4 周就能撑住初级岗的笔试和现场题。

## 笔试策略（先看这个）

- 先做会的题，再啃难题，别在一道题上耗死
- 动手前先讲思路给面试官，哪怕不完美也比闷头写强
- 注意输入输出格式，很多笔试不是不会做，是格式错
- 简单题拿满分 > 中等题写一半，分值一样先稳简单

## 4 周主题

| 周 | 主题 | 核心技巧 | 代表题 |
|----|------|----------|--------|
| 1 | 数组与字符串 | 双指针、滑动窗口、哈希表 | 两数之和、反转字符串、最长公共前缀、无重复最长子串 |
| 2 | 链表与栈队列 | 指针操作、辅助栈 | 反转链表、合并两个有序链表、有效括号、用栈实现队列 |
| 3 | 二分、排序、递归 | 二分模板、归并/快排、递归退出条件 | 二分查找、有序数组去重、爬楼梯 |
| 4 | 动态规划入门 + 综合 | 状态转移、记忆化 | 打家劫舍、最大子数组和、买卖股票时机 |

## 每类题目的通用模板

### 双指针（数组）

```python
left, right = 0, len(arr) - 1
while left < right:
    # 根据条件移动 left 或 right
    left += 1  # 或 right -= 1
```

### 哈希表（查重/找配对）

```python
seen = {}
for x in arr:
    if target - x in seen:
        return [seen[target - x], i]
    seen[x] = i
```

### 递归（先写退出条件）

```python
def solve(n):
    if n <= 1:      # 退出条件放最前
        return n
    return solve(n - 1) + solve(n - 2)  # 记忆化后就是 DP
```

## 面试官追问怎么答

- 问复杂度 → 说"时间 O(n)、空间 O(1)"，并解释为什么
- 问优化 → 先答暴力解，再说"用哈希表/双指针把 O(n^2) 降到 O(n)"
- 问边界 → 空数组、单元素、全相同元素，各跑一遍

## 每天打卡格式

做完一题，用自己的话写三行：题目、思路、复杂度。
写不出来就说明没真懂，回去重看模板再写一遍。
