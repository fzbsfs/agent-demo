# 简历项目描述与自我介绍话术

## 一、简历项目描述（直接抄，按需删减）

### 智能助手 Agent（个人项目）

独立设计并实现一个支持多轮对话的 Agent 系统，核心是
"思考 -> 行动 -> 观察"循环：大模型通过 Function Calling
自主决定调用计算、时间、待办等工具，工具结果回传后再生成最终回答。

- 基于 DeepSeek（OpenAI 兼容协议）实现工具调度，tools 以
  JSON Schema 描述，程序解析结构化调用并执行，支持跨轮记忆
- 实现最简版 RAG：本地知识库切块后，用词频向量 + 余弦相似度
  检索最相关片段，再交由大模型作答，避免把整份文档塞进上下文
- 工具执行加异常处理：try/except 捕获错误并回传历史让模型换策略，
  设置最多 5 轮调用上限防止死循环
- 针对上下文无限增长，设计了"滑动窗口 + 摘要压缩 + 外置记忆"
  三层方案，避免上下文窗口被撑爆
- 用 Streamlit 搭建可视化界面，可直接演示工具调用过程与记忆能力
- 关键取舍：检索先手写以理解原理，生产可平滑替换为
  embedding 模型 + 向量数据库（ChromaDB）；手写循环吃透原理后，
  生产会用 LangGraph 这类图编排框架管理复杂流程

技术栈：Python、OpenAI SDK、Function Calling、RAG、MCP、LangGraph（了解）、Streamlit

## 四、怎么把 Java 经验讲成加分项

不要说"我只是在实训基地跟着小组做"，要说成：

- SpringBoot 让你懂**接口设计**：Agent 调工具本质上也是"接口调用"
- 数据库经验让你懂**状态管理**：待办工具的"状态"就是数据
- 前后端协作让你懂**一个完整系统长什么样**：模型、逻辑、界面三层

一句话串起来：Agent 开发不只是"调 API"，它是把
"模型 + 工具 + 数据 + 界面"组织成一个系统的工程活，而你恰好都有基础。

## 五、常见追问的回答方向

- 「这个项目做了多久」→ 一周左右独立完成，说明从零能独立交付
- 「遇到的最大难点」→ 让大模型稳定返回工具调用，后来用原生
  Function Calling 解决，而不是让模型输出 JSON 自己解析
- 「为什么不做成 LangGraph」→ 先手写循环吃透原理，再上框架不迷路
- 「MCP 和 Function Calling 什么关系」→ Function Calling 管模型
  怎么开口要工具（填表格式），MCP 管工具怎么被程序接到（插座标准），两者配合
